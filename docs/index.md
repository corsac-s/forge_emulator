# Ollee Watch Forge documentation

Forge lets you write your own watchface for the Ollee Watch in a few kilobytes
of JavaScript. You test it in the browser emulator in this repo, then load it
onto the watch.

## Getting started
- [Install and run the emulator](getting-started/install.md)
- [Your first watchface](getting-started/first-watchface.md): step-by-step tutorial
- [Building with AI agents](getting-started/using-ai-agents.md)

## Concepts
- [Architecture](concepts/architecture.md): the sandbox, script slots, what a face can and can't do
- [Lifecycle](concepts/lifecycle.md): `init`, `enter`, `exit`, events and timers
- [Display](concepts/display.md): the segment LCD and what it can show
- [Input](concepts/input.md): buttons, gestures, Bluetooth and clock events
